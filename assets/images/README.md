# Profile Photo

Please place your profile photo here with the filename: **`profile-photo.jpg`**

## Image Requirements:
- **Filename:** `profile-photo.jpg` (or `.png` if you prefer)
- **Recommended size:** 400x400 pixels or larger (square aspect ratio)
- **Format:** JPG or PNG
- **File size:** Keep it under 500KB for fast loading

## Alternative formats:
If you use a different filename or format, update the image path in `index.md`:
- Current path: `/assets/images/profile-photo.jpg`
- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

## Tips:
- Use a square image for best results (the site will display it as a circle)
- Ensure good lighting and a professional appearance
- Consider using a tool like [TinyPNG](https://tinypng.com/) to compress the image if it's too large
